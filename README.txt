# 개인 학습 시스템 — 초기 UI 시안

## 파일
- `index.html`: 반응형 초기 화면과 메뉴
- `data.js`: 공개 가능한 사이트 표시 설정
- `data.json`: 빈 구조 예시일 뿐이며 개인 기록 저장용이 아닙니다.

## 적용 전 주의
1. 기존 저장소의 파일을 교체하기 전에 현재 파일을 별도 백업하세요.
2. 이 버전은 화면 시안입니다. 로그인, DB 저장, 파일 업로드, 실제 검색은 아직 작동하지 않습니다.
3. 개인 기록을 `data.json`에 넣지 마세요. GitHub Pages의 파일은 공개될 수 있습니다.
4. Supabase를 연결하기 전까지 기존 사이트를 운영용으로 교체하지 않는 것을 권장합니다.

## GitHub Pages 적용
저장소 루트에 `index.html`과 `data.js`를 업로드합니다. `data.json`은 이 시안에서 사용하지 않으므로 업로드할 필요가 없습니다.
